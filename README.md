# Laboratorios de Cloud computing dynamic

El código y los pasos de los laboratorios de los videos del canal, para que los hagas en tu propia cuenta de AWS.

| Carpeta | Video | Servicios |
|---|---|---|
| [`04-app-musica`](04-app-musica) | App de música serverless en AWS | CloudFront, S3, Cognito, API Gateway, Lambda, DynamoDB |

Cada carpeta tiene su `pasos.md`, con los pasos en orden y cómo borrarlo todo al final para no pagar de más.

> Usa una cuenta de pruebas, revisa los costos de cada laboratorio y borra los recursos al terminar.
